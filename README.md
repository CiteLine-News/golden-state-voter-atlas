# Golden State Voter Atlas

`Golden State Voter Atlas` is a self-contained HTML, CSS, and JavaScript page for researching the 2026 California gubernatorial race. It is designed as a polished civic dashboard rather than a generic search page.

## What It Does

- Search across candidate names, issue lanes, signature proposals, and source material.
- Filter by party, issue area, and bookmarks.
- Compare up to five candidates side by side.
- Keep a spotlight profile open while reviewing the rest of the field.
- Copy a concise comparison brief or share the current filtered view through the URL.

## Data Scope

- The current build uses a curated starter slate of major active campaigns as of `April 15, 2026`.
- It links back to official campaign sites, the California Secretary of State candidate materials, and the official certified candidate list.
- It is meant to be a transparent research aid, not a full live database of every certified candidate.

## Run

Open `index.html` in a modern browser.

## Files

- `index.html`: page structure
- `styles.css`: California-inspired civic visual system
- `app.js`: candidate data, filtering, bookmarking, compare mode, and shareable state
